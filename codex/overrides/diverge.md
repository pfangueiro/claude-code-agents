# Divergent decision exploration

Use for consequential decisions with several defensible options, rather than factual
lookups or a fix the user already chose. Establish constraints and acceptance checks.

If authorized collaboration exists, assign independent read-only specialists distinct
frames (minimal change, architecture, operations, security, user experience). Give them
the same raw inputs and SHA, without the coordinator's preferred answer. Collect options,
trade-offs and evidence; a separate critic identifies traps, missing constraints and
unsupported assumptions. Verify material claims against source or primary documentation.

Synthesize a recommendation, viable alternatives, irreversible consequences and the
next executable step. If delegation is unavailable, explore frames sequentially and
disclose that they were not independently generated. Do not invent tool access.
