# Structured decision analysis

Use for genuinely open, consequential decisions. Answer factual lookups directly;
use `$deep-read` for source questions and `$investigate` for reproducible unknown defects.

Discover the Sequential Thinking MCP and inspect its tool schema. When connected,
use it to record concise problem/evidence summaries, alternatives, revisions and
verification checkpoints. Supply only the arguments accepted by the exposed tool;
do not assume its server prefix. Never send credentials or private logs to a server.

Frame constraints, compare viable options and traps, identify falsifiable assumptions,
verify them with code/tests/primary sources, and report the recommended action and
remaining uncertainty. If the MCP is missing, state that limitation and perform these
evidence checks locally; do not claim MCP reasoning occurred. Avoid arbitrary thought quotas.
